## Convention

- **Validé** : règle explicitement convenue au cours du cadrage.
- **Proposé** : conception recommandée, à confirmer avant développement.
- **À préciser** : choix fonctionnel, juridique ou opérationnel non arbitré.

Les maquettes, exemples de prix, dates, noms et fournisseurs ne constituent pas des données réelles.
